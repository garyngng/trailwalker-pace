# 毅行者配速 Trailwalker Pace

手機友善嘅 Oxfam Trailwalker 100km 配速追蹤網頁。

- 比賽日：2026-11-20，08:30（香港時間）出發
- 撳 CP1–CP10 即攞電話而家時間
- 顯示已行公里、剩餘距離、目標時段（含 18 小時插值）
- 顯示距離下一個更快／更慢分段差幾多
- 支援加到主畫面（PWA）同離線快取

## 用法

1. 用手機瀏覽器打開呢個網頁
2. **測試模式**：輸入出發時間、到達時間同 CP，撳「計算配速」
3. 比賽日：到達檢查站時直接撳對應 CP（對正式 08:30 計）
4. 目標分段 18／20／22／24／26／28；表顯示每段所需分鐘同預計到達；到達後顯示補給

本地預覽：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```
